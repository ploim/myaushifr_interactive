# AGENTS.md — конвенции проекта

Интерактивный стенд СЗИ: теормодуль «Азбука защиты» и тринадцать сценариев
отражения атак средствами защиты информации. Vite + React + TypeScript,
без бэкенда. Язык интерфейса и коммитов — русский.

## Команды

```bash
export PATH=/opt/homebrew/bin:$PATH   # node 26 вместо системного 18 — ОБЯЗАТЕЛЬНО
npm run dev        # dev-сервер :5173
npm run build      # tsc -b + vite build — типы + сборка, гонять перед сдачей
npm run lint       # eslint ., должен быть без warning'ов
npm run preview    # прод-сборка на :4173
node scripts/preview.mjs   # ASCII-превью пиксель-карт + валидация ширины строк
```

## Структура и правила

- Приложение стартует с приветствия: `WelcomeScreen` → обязательная «Азбука
  защиты» → `ScenarioPicker` → приз. Routing между экранами — state
  `Screen = 'welcome' | 'theory' | 'picker' | 'prize'` в `App.tsx`
  (без URL-роутера). Термин теормодуля = `TheoryTerm` (name/full/icon/text),
  группы: подразделения, средства защиты, механизмы.
- Приключение: сценарий пройден = достигнута финальная сцена; id копятся
  в localStorage (`PROGRESS_KEY = 'meaw-progress'`), цель — `PRIZE_GOAL = 3`.
  Экран приза рендерится только при `done.length >= PRIZE_GOAL`. Прогресс-бар
  и кнопка «Забрать сладкий приз» — в `ScenarioPicker`, салюты и призовая
  модалка — в `PrizeScreen` (тексты для ведущего менять там же). Салюты —
  бесконечная серия залпов (`setInterval` 850 мс, время жизни залпа 2 с,
  константы `BURST_INTERVAL`/`BURST_LIFETIME`), пока открыта модалка;
  закрывает её кнопка «Назад к сценариям».
- `src/data/scenarios.ts` — единственный источник сюжетов (акты, сцены, СЗИ,
  реплики, итоги). UI не хардкодит тексты сценария; новые сцены — только сюда.
  Сценариев тринадцать: письмо, EDR, сеть, IPS, DLP, брутфорс, PAM, IAM,
  NDR, WAF, Honeypot, SOAR, XDR.
- `src/data/stages.ts` — треки узлов: у каждого сценария свой конвейер
  (`MAIL_STAGES`, `EDR_STAGES`, `PAM_STAGES`, …) и свой маркер трека
  (письмо/жук/документ/ключ/пропуск/файл).
- Реплики НЕ редактируются в приложении — тексты живут только в
  `src/data/scenarios.ts` (в UI id реплик не показываются). Пользователь
  ссылается на сценарий и текст реплики; правка — по этим данным.
- Маскот — PNG-спрайты `src/assets/mascot/{mascot-open,mascot-closed}.png`,
  генерируются из исходной картинки: `node scripts/mascot-frames.mjs
  /путь/до/mascot-dod.png`. Ручные правки PNG не коммитить — править скрипт.
  Рот синхронизирован с печатью реплики: `useTypewriter` → prop `talking` →
  CSS `mouth-flap`; при reduced-motion текст появляется целиком. Говорящий
  маскот вне сценариев (приветствие, теория, приз) — `SpeakingMascot`;
  декор поверх кота — проп `overlay` (подарок в лапе на призе — карта
  `GIFT`; рисуется в `.speaker__overlay` с z-index 2 поверх PNG,
  посадка — класс `.speaker-overlay--gift`).
- `src/pixel/maps.ts` — пиксельные карты (значки, иконки узлов, маркеры).
  После ЛЮБОЙ правки запускать `scripts/preview.mjs`: строки карты обязаны
  быть одной длины, превью показывает, как sprite ляжет на экран.
- Иконки узлов красятся через CSS-переменные `--px-*` по `data-state`
  (future/current/passed/blocked/quarantine/delivered/defended) — не
  дублировать палитры в картах.

## Требования к коду

- TypeScript strict; импорты типов через `import type` (verbatimModuleSyntax).
- Доступность обязательна: у интерактивного — роль/aria-label, фокус виден,
  анимации уважают `prefers-reduced-motion`.
- Мобильная адаптация обязательна: без горизонтальной прокрутки от 390px,
  тап-таргеты ≥44px (см. `@media (max-width: 760px)` в `src/index.css`);
  после правок вёрстки проверять узкий экран.
- Каждый видимый элемент управления работает; пустых/декоративных кнопок нет.
- Стили — в `src/index.css` по БЭМ-подобным классам; токены (цвета, шрифты)
  только через `var(--…)` из `:root`.
