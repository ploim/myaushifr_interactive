# Путь письма · демо почтовой защиты

Интерактивная пошаговая демонстрация того, как письмо проходит инфраструктуру
защиты от вредоносных вложений: два сценария — **вредоносное вложение**
(перехват в песочнице, итог «Заблокировано») и **легитимное письмо**
(все проверки пройдены, итог «Доставлено»).

Кот-маскот Мяушифр комментирует каждый шаг от первого лица: реплика
печатается по буквам, а кот «говорит» её — открывает рот в такт печати
(два PNG-кадра, резкие пиксельные переключения). Пользователь может
переписывать реплики в встроенном редакторе — правки живут в
`localStorage` браузера.

## Стек

- [Vite 7](https://vite.dev) + [React 19](https://react.dev) + TypeScript 5.9 (strict)
- ESLint 9 (flat config): typescript-eslint, react-hooks, react-refresh
- Ноль рантайм-зависимостей кроме React: вся пиксельная графика — рукописные
  карты символов → SVG, шрифт Press Start 2P лежит локально (woff2, cyrillic+latin)
- Без бэкенда: статики и `localStorage` достаточно

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

> На этой машине дефолтный `node` — 18-й (nvm), а Vite 7 требует новее.
> Если `npm run dev` ругается на версию — выполните
> `export PATH=/opt/homebrew/bin:$PATH` (там Node 26) и повторите.

Продакшен-сборка и локальный предпросмотр:

```bash
npm run build      # tsc -b + vite build → dist/
npm run preview    # http://localhost:4173
npm run lint       # ESLint
```

## Как устроено

```
src/
  data/
    stages.ts      # 6 узлов конвейера: отправитель → … → ящик/карантин
    scenarios.ts   # два сюжета: акты → сцены, СЗИ, реплики кота, итоги
  assets/mascot/   # маскот: PNG-кадры «рот открыт»/«рот закрыт»
  pixel/
    maps.ts        # пиксельные карты (значки настроений, иконки, конверт)
    PixelSprite.tsx
  hooks/
    useQuotes.ts   # черновик + сохранение реплик в localStorage
    useTypewriter.ts, usePrefersReducedMotion.ts
  components/      # StageMap, ScenePanel, Mascot, FinalCard,
                   # ScenarioPicker, Controls, QuoteEditor
scripts/
  mascot-frames.mjs # пикселизация исходного PNG маскота + кадр «рот закрыт»
  preview.mjs       # ASCII-превью пиксельных карт
```

- **Данные отделены от UI**: сценарии — типизированные структуры в
  `src/data/scenarios.ts`; добавить сцену = добавить объект в массив.
- **Маскот** — пикселизация исходной картинки (`node scripts/mascot-frames.mjs
  /путь/до/mascot-dod.png`): два кадра в `src/assets/mascot/`. Кадр «рот
  закрыт» рисуется скриптом (заливка рта цветом морды + линия-улыбка);
  настраивается детекцией лососевого кластера в `findMouth`.
- **Редактор реплик** (`✎ Реплики кота` в шапке): черновик не теряется при
  переключении шагов, «Сохранить» пишет в `localStorage`
  (ключ `dod-mail-journey.quotes.v1`, только отличия от оригинала),
  «Отменить правки» откатывает черновик, «Сбросить всё» — двухшаговое
  подтверждение с возвратом к исходным текстам.
- **Доступность**: навигация стрелками ←/→, фокус следует за сменой шага,
  `aria-live`-статус, ловушка фокуса и Escape в редакторе, режим
  `prefers-reduced-motion` гасит анимации.
- **Проверка пиксель-арта**: `node scripts/preview.mjs` печатает ASCII-превью
  всех карт и валидирует длину строк — запускать после правок в `maps.ts`.
