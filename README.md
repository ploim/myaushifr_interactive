# Стенд СЗИ · демо защиты информации

Интерактивный стенд из шести сценариев: как средства защиты информации
отражают атаки шаг за шагом. Каждый сюжет — своя инфраструктура, свои
участники-СЗИ и свой итог. Кот-маскот Мяушифр комментирует каждый шаг:
реплика печатается по буквам, а кот «говорит» её — открывает рот в такт
печати (два PNG-кадра, резкие пиксельные переключения).

| # | Сценарий | О чём | Исход |
|---|---|---|---|
| 1 | Вредоносное вложение | Троян в письме против шлюза, антиспама, антивируса и песочницы | Заблокировано |
| 2 | Компрометация АРМ | Фишинг дошёл до рабочего места: EDR-агент → SIEM → SOC → ликвидация | Инцидент ликвидирован |
| 3 | Сетевая атака | Скан периметра, эксплойт, webshell в DMZ и сегментация | Атака отражена |
| 4 | IPS в действии | Один день IPS: сигнатуры, обходы, аномалии, ложняки, политика | Поток очищен |
| 5 | DLP и сотрудник | Инсайдер выносит базу клиентов: почта, USB, облако под присмотром | Утечка предотвращена |
| 6 | Брутфорс паролей | Password spraying против VPN: локраунты, MFA, корреляция SIEM | Перебор остановлен |

## Стек

- [Vite 7](https://vite.dev) + [React 19](https://react.dev) + TypeScript 5.9 (strict)
- ESLint 9 (flat config): typescript-eslint, react-hooks, react-refresh
- Ноль рантайм-зависимостей кроме React: вся пиксельная графика — рукописные
  карты символов → SVG, шрифт Press Start 2P лежит локально (woff2, cyrillic+latin)
- Без бэкенда и хранилищ: только статика

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

> На этой машине дефолтный `node` — 18-й (nvm), а Vite 7 требует новее.
> Если `npm run dev` ругается на версию — выполните
> `export PATH=/opt/homebrew/bin:$PATH` (там Node 26) и повторите.

Продакшен-сборка и локальный предпросмотр:

```bash
npm run build      # tsc -b + vite build → dist/
npm run preview    # http://localhost:4173
npm run lint       # ESLint
```

## Как устроено

```
src/
  data/
    stages.ts      # треки узлов: свой конвейер на каждый сценарий + маркеры
    scenarios.ts   # шесть сюжетов: акты → сцены, СЗИ, реплики кота, итоги
  assets/mascot/   # маскот: PNG-кадры «рот открыт»/«рот закрыт»
  pixel/
    maps.ts        # пиксельные карты (значки настроений, иконки узлов, маркеры)
    PixelSprite.tsx
  hooks/
    useTypewriter.ts, usePrefersReducedMotion.ts
  components/      # StageMap, ScenePanel, Mascot, FinalCard,
                   # ScenarioPicker, Controls
scripts/
  mascot-frames.mjs # пикселизация исходного PNG маскота + кадр «рот закрыт»
  preview.mjs       # ASCII-превью пиксельных карт
```

- **Данные отделены от UI**: сценарии — типизированные структуры в
  `src/data/scenarios.ts`; добавить сцену = добавить объект в массив.
  Трек узлов — тоже данные (`src/data/stages.ts`): у каждого сюжета свой
  конвейер (почтовый путь, цепочка EDR/SOC, периметр с IPS, контур DLP,
  линия VPN/MFA) и свой маркер трека: письмо, жук или документ.
- **Реплики**. Реплики не редактируются в приложении — их тексты живут в
  исходниках. Id реплики видно в интерфейсе: под репликой в бабле
  (`реплика m-s7`) и у цитаты акта. Хотите поменять текст — назовите id,
  правка вносится в `src/data/scenarios.ts`.
- **Маскот** — пикселизация исходной картинки (`node scripts/mascot-frames.mjs
  /путь/до/mascot-dod.png`): два кадра в `src/assets/mascot/`. Кадр «рот
  закрыт» рисуется скриптом (заливка рта цветом морды + линия-улыбка);
  настраивается детекцией лососевого кластера в `findMouth`.
- **Доступность**: навигация стрелками ←/→, фокус следует за сменой шага,
  `aria-live`-статус, режим `prefers-reduced-motion` гасит анимации.
- **Проверка пиксель-арта**: `node scripts/preview.mjs` печатает ASCII-превью
  всех карт и валидирует длину строк — запускать после правок в `maps.ts`.
