# Стенд СЗИ · демо защиты информации

Интерактивный стенд: теоретическая «Азбука защиты» и тринадцать сценариев —
как средства защиты информации отражают атаки шаг за шагом. Каждый сюжет —
своя инфраструктура, свои участники-СЗИ и свой итог. Кот-маскот Мяушифр
комментирует каждый шаг: реплика печатается по буквам, а кот «говорит» её —
открывает рот в такт печати (два PNG-кадра, резкие пиксельные переключения).

Приложение открывается приветственным экраном: Мяушифр рассказывает
о правилах — прочитать «Азбуку защиты» до конца, отразить любые три атаки
и забрать сладкий приз (прогресс хранится в localStorage). Дальше —
обязательный теоретический модуль «Азбука защиты»: короткие объяснения
простыми словами о каждом решении СЗИ и подразделении, которые встречаются
в сценариях; кнопка «К сценариям» ждёт в самом конце страницы.

| # | Сценарий | О чём | Исход |
|---|---|---|---|
| 1 | Вредоносное вложение | Троян в письме против шлюза, антиспама, антивируса и песочницы | Заблокировано |
| 2 | Компрометация АРМ | Фишинг дошёл до рабочего места: EDR-агент → SIEM → SOC → ликвидация | Инцидент ликвидирован |

| 5 | DLP и сотрудник | Инсайдер выносит базу клиентов: почта, USB, облако под присмотром | Утечка предотвращена |
| 6 | Брутфорс паролей | Password spraying против VPN: локраунты, MFA, корреляция SIEM | Перебор остановлен |
| 7 | Привилегированный доступ | Злоумышленник с чужим сейфом паролей против PAM: заявки, сессии под записью, аудит | Секрет остался в сейфе |

## Стек

- [Vite 7](https://vite.dev) + [React 19](https://react.dev) + TypeScript 5.9 (strict)
- ESLint 9 (flat config): typescript-eslint, react-hooks, react-refresh
- Ноль рантайм-зависимостей кроме React: вся пиксельная графика — рукописные
  карты символов → SVG, шрифт Press Start 2P лежит локально (woff2, cyrillic+latin)
- Без бэкенда и хранилищ: только статика

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

> На этой машине дефолтный `node` — 18-й (nvm), а Vite 7 требует новее.
> Если `npm run dev` ругается на версию — выполните
> `export PATH=/opt/homebrew/bin:$PATH` (там Node 26) и повторите.

Продакшен-сборка и локальный предпросмотр:

```bash
npm run build      # tsc -b + vite build → dist/
npm run preview    # http://localhost:4173
npm run lint       # ESLint
```

## Как устроено

```
src/
  data/
    theory.ts      # «Азбука защиты»: подразделения, СЗИ, механизмы — по 2–3
                   # предложения простыми словами
    stages.ts      # треки узлов: свой конвейер на каждый сценарий + маркеры
    scenarios.ts   # тринадцать сюжетов: акты → сцены, СЗИ, реплики кота, итоги
  assets/mascot/   # маскот: PNG-кадры «рот открыт»/«рот закрыт»
  pixel/
    maps.ts        # пиксельные карты (значки настроений, иконки узлов, маркеры)
    PixelSprite.tsx
  hooks/
    useTypewriter.ts, usePrefersReducedMotion.ts
  components/      # WelcomeScreen, TheoryScreen, ScenarioPicker, PrizeScreen,
                   # SpeakingMascot, StageMap, ScenePanel, Mascot, FinalCard,
                   # Controls
scripts/
  mascot-frames.mjs # пикселизация исходного PNG маскота + кадр «рот закрыт»
  preview.mjs       # ASCII-превью пиксельных карт
```

- **Экраны и приключение**. State `Screen = 'welcome' | 'theory' | 'picker'
  | 'prize'` в `App.tsx` (без URL-роутера). Старт — приветствие Мяушифра
  (`WelcomeScreen`), затем обязательная «Азбука защиты» (`TheoryScreen`,
  кнопка «К сценариям →» только в конце страницы), затем выбор сюжета
  (`ScenarioPicker` с прогресс-баром). Сценарий считается пройденным, когда
  игрок дошёл до финальной сцены; пройденные id копятся в localStorage
  (ключ `meaw-progress`). После трёх пройденных появляется блестящая кнопка
  «Забрать сладкий приз» → `PrizeScreen`: поздравление, пиксельные салюты
  и модальное сообщение для ведущего.
- **Данные отделены от UI**: сценарии — типизированные структуры в
  `src/data/scenarios.ts`; добавить сцену = добавить объект в массив.
  Трек узлов — тоже данные (`src/data/stages.ts`): у каждого сюжета свой
  конвейер (почтовый путь, цепочка EDR/SOC, периметр с IPS, контур DLP,
  линия VPN/MFA, сейф PAM, каталог IAM, сенсор NDR, WAF, ловушка-горшок,
  оркестратор SOAR, телеметрия XDR) и свой маркер трека.
- **Реплики**. Реплики не редактируются в приложении — их тексты живут в
  исходниках. Ссылайтесь на сценарий и текст реплики; правка вносится
  в `src/data/scenarios.ts`.
- **Маскот** — пикселизация исходной картинки (`node scripts/mascot-frames.mjs
  /путь/до/mascot-dod.png`): два кадра в `src/assets/mascot/`. Кадр «рот
  закрыт» рисуется скриптом (заливка рта цветом морды + линия-улыбка);
  настраивается детекцией лососевого кластера в `findMouth`.
- **Доступность**: навигация стрелками ←/→, фокус следует за сменой шага,
  `aria-live`-статус, режим `prefers-reduced-motion` гасит анимации.
  Говорящий маскот вне сценариев — компонент `SpeakingMascot` (печать
  реплики + открывающийся рот); академический колпак на «Азбуке» — карта
  `CAP` из `maps.ts`, кладётся поверх маскота абсолютным позиционированием.
- **Мобильные устройства**: адаптив от 390px — вертикальный трек узлов,
  кнопки не меньше пальца (≥44px), карточки терминов и сценария в одну
  колонку, без горизонтальной прокрутки.
- **Проверка пиксель-арта**: `node scripts/preview.mjs` печатает ASCII-превью
  всех карт и валидирует длину строк — запускать после правок в `maps.ts`.
